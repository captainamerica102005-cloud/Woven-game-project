# Woven

Woven is a story driven RPG that focuses on the relationship between a 24 year old man named Nick, and a goofy lovable plush toy, with a slight edge named Donny.

## About

Nick and Donny must make their way through the world of Woven, Villains, and Difficult truths.

## Status

In development, currently missing a massive list of features that are subject to change at any time.

## Made with

- Godot and GDscript

## How to run

1. Install Godot 4.6
2. Clone or download this repository.
3. Open and run in Godot.
